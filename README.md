NGS / PSO2 の5つのシミュレーターをまとめたランチャーです。

## 使い方

このリポジトリを ZIP でダウンロードして展開し、ルートの `index.html` をブラウザーで開いてください。インストールは不要です。フォルダー構成を保ったまま利用できます。

アイコンをクリックすると、シミュレーターを新しいタブで開きます。初回の表示言語は日本語です。言語・テーマの選択はブラウザーに保存されます。

## シミュレーター

フォルダー名は英語で統一しています。ルートの `index.html` から各シミュレーターを開けます。

```text
index.html
ngs-equipment/
pso2-equipment/
pso2-affix/
pso2-skills/
pso2-candy-box/
launcher-assets/
backgrounds/
```
