集中启动 5 个 NGS / PSO2 模拟器。

## 使用

下载本仓库 ZIP 并解压，直接用浏览器打开根目录的 `index.html`，保持文件夹结构即可，无需安装。

点击图标会在新标签页打开模拟器。首次默认日语，之后记住浏览器中选择的语言和主题。

## 模拟器

文件夹统一使用英文名称，从根目录的 `index.html` 进入各模拟器。

```text
index.html
ngs-equipment/
pso2-equipment/
pso2-affix/
pso2-skills/
pso2-candy-box/
launcher-assets/
backgrounds/
```
